# BTC 30m — موقع الموديل

موقع Flask بسيط يعرض موديل التوقع وبيانات التدريب والتحليل المباشر والنتائج، مع منطقة خاصة لإدارة ملفات الموديل.

## الصفحات

| الصفحة | المسار | المحتوى |
|---|---|---|
| الموديل والبيانات | `/` | إعدادات الموديل، المؤشرات، الهدف، بيانات التدريب، SHA-256 |
| التحليل المباشر | `/live` | آخر شموع Binance، توقع الموديل، آخر 30 شمعة، تحديث كل 15 ثانية |
| النتائج | `/results` | نتائج حالية وقديمة، اختيار العتبة 0.58 أو 0.60، رسم الربح التراكمي، الجدول الشهري |
| خاص | `/admin` | قائمة ملفات الموديل، تحميل، رفع نسخة جديدة (محمية بكلمة مرور) |

API: `/api/live` يرجع JSON بآخر توقع.

## هيكل المجلدات

```
btc_site/
  app.py               التطبيق والمسارات
  predictor.py         حساب المؤشرات والتوقع وجلب بيانات Binance
  model/               BTC_30m_model_058.npz  (الموديل)
  results/             مجلد لكل نسخة من النتائج (run_...)
  site_data/           data_info.json (ملخص بيانات التدريب) وREADME الأصلي
  templates/           القوالب
  static/style.css     التنسيق
```

لإضافة نسخة نتائج جديدة: أنشئ مجلداً جديداً داخل `results/` (مثلاً `run_2026-11-01`) وضع فيه ملفات `walkforward_monthly_th0.58.csv` وغيرها. سيظهر تلقائياً في القائمة، والأحدث بالاسم يظهر أولاً.

## التشغيل

```bash
pip install -r requirements.txt

# للتجربة المحلية
ADMIN_USER=admin ADMIN_PASS="كلمة_سر_قوية" python app.py
# ثم افتح http://127.0.0.1:5000

# للإنتاج
ADMIN_USER=admin ADMIN_PASS="كلمة_سر_قوية" gunicorn -w 1 -b 0.0.0.0:8000 app:app
```

ملاحظات:
- إذا لم تضبط `ADMIN_USER` و`ADMIN_PASS` تبقى المنطقة الخاصة معطلة (503).
- استخدم `-w 1` في gunicorn لأن الموديل وذاكرة التخزين المؤقت للتحليل المباشر داخل العملية.
- التحليل المباشر يحتاج اتصالاً بالإنترنت للوصول إلى Binance. إذا تعذر الوصول تظهر رسالة خطأ في الصفحة بدلاً من التوقف.
- ضع الموقع خلف HTTPS عند نشره على الإنترنت، لأن كلمة المرور تُرسل مع كل طلب للمنطقة الخاصة.

## التحقق

- النموذج في `predictor.py` يعطي نفس احتمالات `joblib` الأصلي بفرق ‎~1e-16 على آخر 160 صفاً من بيانات التدريب.
- حساب `vwap` في الحي مطابق لتعريفه في بيانات التدريب (فرق صفر).

## تنبيه

هذا الموقع للاختبار والبحث فقط. الموديل يعطي ميزة إحصائية صغيرة جداً، وليس ضماناً للربح، وليس نصيحة مالية.
